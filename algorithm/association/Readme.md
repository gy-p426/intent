# 多元关联分析 (Multivariate Association Analysis)

### 1.算法简介

多元关联分析算法支持三种分析模式，能够分析变量之间的关联关系：

1. **二元关联分析（Bivariate）**: 分析两个变量之间的关联关系
2. **多变量两两关联分析（Pairwise）**: 分析多个变量之间的两两关联关系
3. **多变量综合关联分析（Multivariate）**: 分析多个自变量与一个因变量的综合关联关系

#### 算法原理

- **自动模式识别**: 根据列数和用户意图自动选择合适的分析模式
- **智能方法选择**: 根据数据类型和分析模式自动选择最合适的统计方法
- **统计分析**: 执行相应的统计检验，计算统计量、P 值和效应量
- **结果解释**: 提供易于理解的文字解释

#### 支持的分析模式和方法

| 模式 | 列数要求 | 方法 | 适用场景 |
| --- | --- | --- | --- |
| **Bivariate（二元）** | 恰好2列 | 卡方检验/相关性分析/方差分析 | 分析两个变量的关联 |
| **Pairwise（两两）** | 至少3列 | 互信息(MI) | 找出多个变量中哪些相互关联 |
| **Multivariate（综合）** | 至少3列 | 条件互信息(CMI) + 回归 | 分析多个因素对目标变量的影响 |

#### 主要特点

- ✅ **多模式支持**: 支持二元、两两、综合三种分析模式
- ✅ **自动模式推断**: 根据列数自动选择合适的分析模式
- ✅ **智能方法选择**: 根据数据类型自动选择最合适的分析方法
- ✅ **完整统计结果**: 提供统计量、P 值、效应量等完整指标
- ✅ **结果解释**: 提供易于理解的文字解释
- ✅ **向后兼容**: 完全兼容旧版本的二元关联分析接口

### 2.参数说明

#### （1）必需参数

- **columns** (array): 需要分析的列名数组
  - 至少2列
  - 对于multivariate模式，第一列为因变量
  - 示例: `["age", "salary"]` 或 `["salary", "age", "education", "experience"]`

#### （2）可选参数

- **analysis_mode** (string): 分析模式，默认值：根据列数自动推断
  - 可选值:
    - `"bivariate"` - 二元关联分析（2列）
    - `"pairwise"` - 多变量两两关联分析（≥3列）
    - `"multivariate"` - 多变量综合关联分析（≥3列，第一列为因变量）
  - 如果不指定，系统会自动推断：
    - 2列 → `bivariate`
    - ≥3列 → `pairwise`（默认）

- **significance_level** (float): 显著性水平（保留用于向后兼容），默认值：`0.05`
  - 取值范围: `0.001` ~ `0.5`
  - 常用值: `0.01`, `0.05`, `0.1`

#### （3）数据要求

- 每列至少需要 **2 个数据点**
- 所有列数据长度必须 **完全相同**
- 数据可以包含缺失值（系统会自动处理）
- 清洗后有效数据点少于 2 个时将报错
- **模式特定要求**:
  - `bivariate`: 恰好2列
  - `pairwise`: 至少3列
  - `multivariate`: 至少3列

### 3.使用场景

#### 场景 1: 二元关联分析（Bivariate）

**用户问题**: "员工年龄和薪资有什么关系？"

**分析模式**: `bivariate`

**输入示例**:
```json
{
  "columns": ["age", "salary"]
}
```

**预期结果**:
- 自动选择合适的方法（相关性分析/卡方检验/方差分析）
- Pearson/Spearman 相关系数
- P 值和效应量
- 相关方向和强度

---

#### 场景 2: 多变量两两关联分析（Pairwise）

**用户问题**: "分析年龄、学历、工作年限之间的关联关系"

**分析模式**: `pairwise`

**输入示例**:
```json
{
  "columns": ["age", "education", "experience"],
  "analysis_mode": "pairwise"
}
```

**预期结果**:
- 互信息矩阵
- 所有变量对的关联强度
- 显著关联的变量对列表
- 热力图数据（可选）

---

#### 场景 3: 多变量综合关联分析（Multivariate）

**用户问题**: "哪些因素影响员工薪资？"

**分析模式**: `multivariate`（薪资为因变量，放在第一位）

**输入示例**:
```json
{
  "columns": ["salary", "age", "education", "experience"],
  "analysis_mode": "multivariate"
}
```

**预期结果**:
- 条件互信息(CMI)值
- 回归分析结果
- 每个自变量的贡献度
- 综合影响评估

---

### 4.输入输出格式

#### 输入格式（新格式）

```json
{
  "data": [
    {"name": "age", "values": [25, 30, 35, 40]},
    {"name": "salary", "values": [50000, 80000, 100000, 120000]},
    {"name": "education", "values": ["本科", "硕士", "博士", "硕士"]}
  ],
  "options": {
    "analysis_mode": "pairwise"
  }
}
```

```json
{
  "data": {
    "column1": {
      "name": "age",
      "values": [25, 30, 35, 40]
    },
    "column2": {
      "name": "salary",
      "values": [50000, 80000, 100000, 120000]
    }
  },
  "options": {
    "significance_level": 0.05
  }
}
```

```json
{
  "解释": "自然语言描述分析结果",
  "算法结果": {
    "方法": "互信息 | 卡方检验 | 相关性分析 | 方差分析 | 条件互信息+回归",
    "使用模式": "bivariate | pairwise | multivariate",
    "结论摘要": {
      "存在依赖的变量对": ["education-salary", "experience-salary"],
      "不存在显著依赖的变量对": ["age-gender"]
    },
    "显著性": {
      "判定方式": "基于P值阈值",
      "阈值": 0.05

      // 根据不同模式返回不同的详细信息
    }
  }
}
```
