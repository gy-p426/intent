
# 密度聚类算法 DBSCAN

## 算法简介

密度聚类算法是一种基于数据点的局部密度分布，将密度相连的连续区域划分为同一聚类，同时能自然识别出任意形状聚类和孤立噪声点的无监督学习算法。

根据输入数据划分不同聚类，不在聚类中的数据为异常点。本算法可同时用于异常分析和聚类。

## 参数说明

### 必需参数

- **id_column**: 用于标识每个数据点的ID列
- **feature_columns**: 用于聚类计算的数值型特征列列表

## 数据要求

1. 适用于1-10维数值型特征列：至少需要1个数值型特征列，最多10维数值型特征列
2. 数据需存在明显的密度差异，如果数据整体密度均匀（如完全随机分布），或簇与簇之间没有明显的密度间隙，算法会难以有效划分聚类。
3. 至少需要一行数据，但是数据行过少可能会导致聚类效果不佳

## 使用示例

### 销售异常分析
```
用户问题: "请帮我分析一下A分公司7-9月份销售数据有哪些异常？"
预期输出:
{
  "parameter_mapping": {
    "id_column": "销售日期",
    "feature_columns": ["销量", "销售额"],
  }
}
```

## 开发指南

### 修改提示词
在 `extractor.py` 的 `build_extraction_prompt` 方法中修改系统提示词和用户提示词。

### 修改数据处理逻辑
在 `processor.py` 中修改数据转换和验证逻辑。

### 添加测试用例
在 `tests/` 目录下添加相应的测试用例。

## 注意事项

1. 确保提示词中要求LLM使用数据库中实际存在的列名
2. 数据处理时要进行适当的数值化和清洗
3. 验证逻辑要严格检查数据质量和参数有效性
