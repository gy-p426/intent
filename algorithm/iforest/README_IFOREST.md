
# 孤立森林算法 IFOREST

## 算法简介

孤立森林是一种基于随机子空间划分的无监督异常检测算法，通过构建多棵孤立树快速孤立占比少、易被划分的异常点，实现高效的异常识别。

## 参数说明

### 必需参数

- **id_column**: 用于标识每个数据点的ID列
- **feature_columns**: 用于异常分析的数值型特征列列表

## 数据要求

1. 适用于1-50维数值型特征列：至少需要1个数值型特征列(低于10维度也可以选择密度聚类算法)，最多50维数值型特征列（多于50维需要进行降维）
2. 至少需要一行数据，但是数据行过少可能会导致聚类效果不佳
3. 对缺失值敏感，算法本身没有对缺失值的处理逻辑，需要提前对缺失值进行填充
4. 异常样本比例通常不能大于20%，异常样本过多会导致异常点难以被快速孤立，会出现大量误判

## 使用示例

### 销售异常分析
```
用户问题: "请帮我分析一下A分公司7-9月份销售数据有哪些异常？"
预期输出:
{
  "parameter_mapping": {
    "id_column": "销售日期",
    "feature_columns": ["销量", "销售额"],
  }
}
```

## 开发指南

### 修改提示词
在 `extractor.py` 的 `build_extraction_prompt` 方法中修改系统提示词和用户提示词。

### 修改数据处理逻辑
在 `processor.py` 中修改数据转换和验证逻辑。

### 添加测试用例
在 `tests/` 目录下添加相应的测试用例。

## 注意事项

1. 确保提示词中要求LLM使用数据库中实际存在的列名
2. 数据处理时要进行适当的数值化和清洗
3. 验证逻辑要严格检查数据质量和参数有效性
