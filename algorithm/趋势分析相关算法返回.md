## 1. 趋势分析算法

### 1.1 趋势分解返回结构

当 `analysis_type = "decomposition"` 时返回：

```json
{
  "data_characteristics": {
    "data_points": 100,
    "mean": 1234.56,
    "std": 123.45,
    "min": 800.0,
    "max": 1600.0,
    "outlier_count": 3,
    "outlier_ratio": 0.03,
    "is_normal": true,
    "has_seasonality": true
  },
  "decomposition": {
    "trend": [
      {"timestamp": "2024-01-01T00:00:00", "value": 1200.5},
      {"timestamp": "2024-01-01T01:00:00", "value": 1201.2}
    ],
    "seasonal": [
      {"timestamp": "2024-01-01T00:00:00", "value": 34.56},
      {"timestamp": "2024-01-01T01:00:00", "value": 32.18}
    ],
    "residual": [
      {"timestamp": "2024-01-01T00:00:00", "value": 0.94},
      {"timestamp": "2024-01-01T01:00:00", "value": -1.38}
    ],
    "analysis_metrics": {
      "trend_strength": 0.85,
      "seasonal_strength": 0.72,
      "residual_variance": 15.23,
      "algorithm": "STL",
      "period_used": 24
    }
  },
  "analysis_type": "decomposition",
  "algorithm_used": "stl",
  "period_used": 24,
  "data_points": 100
}
```

#### 字段说明

| 字段路径 | 类型 | 说明 |
|----------|------|------|
| `data_characteristics` | object | 数据特征分析结果 |
| `data_characteristics.data_points` | integer | 数据点总数 |
| `data_characteristics.mean` | float | 数据均值 |
| `data_characteristics.std` | float | 数据标准差 |
| `data_characteristics.min` | float | 数据最小值 |
| `data_characteristics.max` | float | 数据最大值 |
| `data_characteristics.outlier_count` | integer | 异常值数量 |
| `data_characteristics.outlier_ratio` | float | 异常值比例 (0-1) |
| `data_characteristics.is_normal` | boolean | 是否符合正态分布 |
| `data_characteristics.has_seasonality` | boolean | 是否存在季节性 |
| `decomposition` | object | 分解结果 |
| `decomposition.trend` | array | 趋势分量时间序列 |
| `decomposition.seasonal` | array | 季节性分量时间序列 |
| `decomposition.residual` | array | 残差分量时间序列 |
| `decomposition.analysis_metrics` | object | 分解分析指标 |
| `decomposition.analysis_metrics.trend_strength` | float | 趋势强度 (0-1) |
| `decomposition.analysis_metrics.seasonal_strength` | float | 季节性强度 (0-1) |
| `decomposition.analysis_metrics.residual_variance` | float | 残差方差 |
| `decomposition.analysis_metrics.algorithm` | string | 使用的分解算法 ("STL" 或 "Classical") |
| `decomposition.analysis_metrics.model_type` | string | 分解模型类型 (仅Classical算法返回，"additive" 或 "multiplicative") |
| `decomposition.analysis_metrics.period_used` | integer | 使用的季节周期 |
| `analysis_type` | string | 分析类型，固定为 "decomposition" |
| `algorithm_used` | string | 使用的算法 ("stl" 或 "classical") |
| `period_used` | integer | 使用的季节周期 |
| `data_points` | integer | 数据点总数 |

### 1.2 趋势检测返回结构

当 `analysis_type = "detection"` 时返回：

#### Mann-Kendall 检验结果

```json
{
  "data_characteristics": {
    "data_points": 100,
    "mean": 1234.56,
    "std": 123.45,
    "min": 800.0,
    "max": 1600.0,
    "outlier_count": 3,
    "outlier_ratio": 0.03
  },
  "detection": {
    "trend_direction": "increasing",
    "sen_slope": 0.0234,
    "p_value": 0.0012,
    "z_statistic": 3.24,
    "s_statistic": 1250,
    "statistical_significance": true,
    "confidence_level": 0.95,
    "method": "Mann-Kendall",
    "sample_size": 100,
    "interpretation": "检测到明显的上升趋势，趋势斜率: 0.0234"
  },
  "analysis_type": "detection",
  "method_used": "mann_kendall",
  "data_points": 100
}
```

#### 线性回归检验结果

```json
{
  "data_characteristics": {
    "data_points": 100,
    "mean": 1234.56,
    "std": 123.45
  },
  "detection": {
    "trend_direction": "increasing",
    "slope": 0.0234,
    "intercept": 1100.5,
    "p_value": 0.0008,
    "r_squared": 0.72,
    "std_error": 0.0056,
    "confidence_interval": [0.0124, 0.0344],
    "statistical_significance": true,
    "confidence_level": 0.95,
    "method": "Linear Regression",
    "sample_size": 100,
    "interpretation": "检测到明显的上升趋势，趋势斜率: 0.0234"
  },
  "analysis_type": "detection",
  "method_used": "linear_regression",
  "data_points": 100
}
```

#### 字段说明

| 字段路径 | 类型 | 说明 |
|----------|------|------|
| `detection.trend_direction` | string | 趋势方向: "increasing"(上升), "decreasing"(下降), "no trend"(无趋势) |
| `detection.sen_slope` | float | Sen斜率估计 (Mann-Kendall) |
| `detection.slope` | float | 回归斜率 (线性回归) |
| `detection.intercept` | float | 回归截距 (线性回归) |
| `detection.p_value` | float | 统计检验p值 |
| `detection.z_statistic` | float | Z统计量 (Mann-Kendall) |
| `detection.s_statistic` | integer | S统计量 (Mann-Kendall) |
| `detection.r_squared` | float | R²决定系数 (线性回归) |
| `detection.std_error` | float | 标准误差 (线性回归) |
| `detection.confidence_interval` | array[float] | 斜率置信区间 [下界, 上界] (线性回归) |
| `detection.statistical_significance` | boolean | 是否统计显著 |
| `detection.confidence_level` | float | 置信水平 |
| `detection.method` | string | 检测方法名称 |
| `detection.sample_size` | integer | 样本量 |
| `detection.interpretation` | string | 结果解释（中文） |

## 2. 单变量预测算法

### 2.1 成功响应结构

```json
{
  "success": true,
  "results": {
    "forecast": [110.5, 112.3, 115.0, 118.2, 120.1],
    "timestamps": [
      "2024-01-15 00:00",
      "2024-01-15 01:00",
      "2024-01-15 02:00",
      "2024-01-15 03:00",
      "2024-01-15 04:00"
    ],
    "confidence_lower": [105.2, 107.1, 109.5, 112.0, 114.2],
    "confidence_upper": [115.8, 117.5, 120.5, 124.4, 126.0],
    "training_data_points": 168,
    "forecast_horizon": 5,
    "training_date_range": {
      "start": "2024-01-08 00:00:00",
      "end": "2024-01-14 23:00:00"
    }
  },
  "model_used": "prophet",
  "data_analysis": {
    "data_points": 168,
    "mean": 108.5,
    "std": 12.3,
    "min": 85.2,
    "max": 135.6,
    "has_seasonality": true,
    "trend_direction": "increasing",
    "missing_ratio": 0.0
  },
  "forecast_horizon": 5
}
```

#### 字段说明

| 字段路径 | 类型 | 说明 |
|----------|------|------|
| `success` | boolean | 预测是否成功 |
| `results` | object | 预测结果 |
| `results.forecast` | array[float] | 预测值数组 |
| `results.timestamps` | array[string] | 预测时间点数组 |
| `results.confidence_lower` | array[float] | 置信区间下界数组 |
| `results.confidence_upper` | array[float] | 置信区间上界数组 |
| `results.training_data_points` | integer | 训练数据点数 |
| `results.forecast_horizon` | integer | 预测步数 |
| `results.training_date_range` | object | 训练数据时间范围 |
| `results.training_date_range.start` | string | 训练数据起始时间 |
| `results.training_date_range.end` | string | 训练数据结束时间 |
| `model_used` | string | 使用的模型: "prophet" 或 "arima" |
| `data_analysis` | object | 数据分析结果 |
| `data_analysis.data_points` | integer | 数据点总数 |
| `data_analysis.mean` | float | 数据均值 |
| `data_analysis.std` | float | 数据标准差 |
| `data_analysis.min` | float | 数据最小值 |
| `data_analysis.max` | float | 数据最大值 |
| `data_analysis.has_seasonality` | boolean | 是否存在季节性 |
| `data_analysis.trend_direction` | string | 趋势方向 |
| `data_analysis.missing_ratio` | float | 缺失值比例 |
| `forecast_horizon` | integer | 预测步数 |

### 2.2 失败响应结构

```json
{
  "success": false,
  "message": "预测失败: 数据点不足，至少需要10个数据点",
  "model_used": "prophet",
  "error_details": {
    "error": "数据点不足，至少需要10个数据点",
    "traceback": "..."
  }
}
```

## 3. 多变量预测算法

### 3.1 新模型训练预测响应

```json
{
  "success": true,
  "results": {
    "timestamps": [
      "2024-01-15 00:00",
      "2024-01-16 00:00",
      "2024-01-17 00:00"
    ],
    "forecast": [123.45, 126.78, 130.12],
    "horizon": 3
  },
  "model_used": "lightgbm",
  "model_id": "mv_abc12345",
  "model_name": "sales_forecast_model",
  "data_analysis": {
    "data_points": 100,
    "target_stats": {
      "mean": 115.5,
      "std": 25.3,
      "min": 65.2,
      "max": 180.6
    },
    "feature_count": 5,
    "missing_values": 0
  },
  "metrics": {
    "rmse": 5.23,
    "mae": 3.45,
    "r2": 0.89
  },
  "reused_model": false
}
```

### 3.2 复用已有模型预测响应

```json
{
  "success": true,
  "results": {
    "timestamps": ["2024-01-15 00:00", "2024-01-16 00:00"],
    "forecast": [125.67, 128.90],
    "horizon": 2
  },
  "model_used": "lightgbm",
  "model_id": "mv_abc12345",
  "model_name": "sales_forecast_model",
  "model_version": 1,
  "reused_model": true
}
```

#### 字段说明

| 字段路径 | 类型 | 说明 |
|----------|------|------|
| `success` | boolean | 预测是否成功 |
| `results` | object | 预测结果 |
| `results.timestamps` | array[string] | 预测时间点数组 |
| `results.forecast` | array[float] | 预测值数组 |
| `results.horizon` | integer | 预测步数 |
| `model_used` | string | 使用的算法: "lightgbm", "xgboost", "random_forest", "linear_regression" |
| `model_id` | string | 模型唯一标识符 (格式: "mv_xxxxxxxx") |
| `model_name` | string | 用户指定的模型名称 (可选) |
| `model_version` | integer | 模型版本号 (复用模型时返回) |
| `data_analysis` | object | 数据分析结果 (新训练时返回) |
| `data_analysis.data_points` | integer | 数据点总数 |
| `data_analysis.target_stats` | object | 目标变量统计信息 |
| `data_analysis.target_stats.mean` | float | 目标变量均值 |
| `data_analysis.target_stats.std` | float | 目标变量标准差 |
| `data_analysis.target_stats.min` | float | 目标变量最小值 |
| `data_analysis.target_stats.max` | float | 目标变量最大值 |
| `data_analysis.feature_count` | integer | 特征数量 |
| `data_analysis.missing_values` | integer | 缺失值总数 |
| `metrics` | object | 模型评估指标 (新训练时返回) |
| `metrics.rmse` | float | 均方根误差 (Root Mean Square Error) |
| `metrics.mae` | float | 平均绝对误差 (Mean Absolute Error) |
| `metrics.r2` | float | R²决定系数 (0-1，越接近1越好) |
| `reused_model` | boolean | 是否复用已有模型 |

### 3.3 失败响应结构

```json
{
  "success": false,
  "message": "目标列 sales_amount 不存在"
}
```

## 4. 通用错误响应

所有算法在发生错误时返回统一的错误结构：

```json
{
  "success": false,
  "message": "错误描述信息",
  "error_details": {
    "error": "详细错误信息",
    "traceback": "错误堆栈信息（仅调试模式）"
  }
}
```

### 常见错误码

| 错误类型 | 错误信息示例 |
|----------|--------------|
| 数据不足 | "数据点不足，至少需要10个数据点" |
| 列不存在 | "目标列 xxx 不存在" |
| 数据格式错误 | "数据格式错误: timestamp列无法解析" |
| 模型不存在 | "模型不存在: mv_xxx" |
| 算法不支持 | "不支持的算法类型: xxx" |
| 周期不足 | "STL分解需要至少2个完整周期的数据" |
