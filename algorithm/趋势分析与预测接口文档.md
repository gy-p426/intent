## 1. 返回数据总览

### 1.1 我会收到什么？

当用户提问后，系统会返回一个 JSON 对象，包含以下主要内容：

```
┌─────────────────────────────────────────────────────────────┐
│                      返回数据结构                            │
├─────────────────────────────────────────────────────────────┤
│  step          → 当前执行到哪一步了                          │
│  status        → 这一步是否成功                              │
│  data          → 具体的数据内容（重点关注这里）               │
│  timestamp     → 返回时间                                    │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 完整返回示例

```json
{
  "step": "completed",
  "status": "completed",
  "data": {
    "algorithm_type": "trend",
    "algorithm_type_chinese": "趋势分析",
    "algorithm_result": { /* 算法原始结果 */ },
    "sql_statement": "SELECT timestamp, value FROM sales_data ORDER BY timestamp",
    "normalized_query": "分析销售数据的趋势变化",
    "execution_summary": "趋势分析完成，检测到上升趋势",
    "data_summary": {
      "input_rows": 100,
      "sql_execution_time": 125
    },
    "readable_result": {
      "llm_analysis": "根据分析结果，您的销售数据呈现明显的上升趋势...",
      "technical_details": { /* 技术细节 */ },
      "analysis_source": "llm_enhanced"
    },
    "message": "趋势分析算法执行完成"
  },
  "timestamp": "2024-12-29T10:30:00.000Z"
}
```

### 1.3 字段说明（通俗版）

| 字段名 | 是什么意思 | 举例 |
|--------|-----------|------|
| `step` | 当前执行到哪一步 | `"completed"` 表示全部完成 |
| `status` | 这一步成功了吗 | `"completed"` 成功，`"error"` 失败 |
| `data.algorithm_type` | 用的是什么算法 | `"trend"` 趋势分析，`"predict"` 预测 |
| `data.algorithm_type_chinese` | 算法的中文名 | "趋势分析"、"预测分析" |
| `data.algorithm_result` | 算法计算出的原始数据 | 用于画图表 |
| `data.readable_result` | **🌟 最重要！给用户看的分析结果** | 自然语言描述 |
| `data.message` | 简短的状态消息 | "趋势分析算法执行完成" |
| `data.sql_statement` | 执行的SQL语句 | 用于调试 |
| `data.data_summary` | 数据摘要信息 | 输入行数、执行时间等 |

## 2. 智能分析结果（readable_result）

### 2.1 这是什么？

`readable_result` 是系统用 AI 自动生成的**用户友好的分析报告**。

**简单说**：这就是你要展示给用户看的主要内容！

### 2.2 结构说明

```json
{
  "readable_result": {
    "llm_analysis": "这里是给用户看的分析文字...",
    "technical_details": {
      "summary": "算法执行完成",
      "status": "success",
      "timestamp": "2024-12-29T10:30:00.000Z",
      "metrics": { /* 关键指标 */ },
      "raw_data": { /* 原始数据摘要 */ }
    },
    "analysis_source": "llm_enhanced"
  }
}
```

### 2.3 字段详解

| 字段 | 是什么 | 前端怎么用 |
|------|--------|-----------|
| `llm_analysis` | **给用户看的分析文字** | 直接显示在页面上，这是最重要的内容 |
| `technical_details` | 技术细节（给想深入了解的用户看） | 可以做成"展开查看详情"的折叠区域 |
| `analysis_source` | 分析是怎么生成的 | 用来显示一个小标签 |

### 2.4 analysis_source 的含义

| 值 | 意思 | 建议显示 |
|----|------|---------|
| `llm_enhanced` | AI 智能分析生成的 | 显示 "🤖 AI智能分析" 标签 |
| `fallback` | 系统自动生成的基础分析 | 显示 "📊 基础分析" 标签 |

## 3. 趋势分析算法

### 3.1 这个算法是干什么的？

趋势分析用来回答这类问题：
- "销售额是在涨还是在跌？"
- "数据有没有周期性规律？"
- "这个趋势明显吗？"

趋势分析有两种模式：
- **趋势分解**（decomposition）：把数据拆成趋势、季节性、随机波动三部分
- **趋势检测**（detection）：判断数据是涨是跌，给出统计结论

### 3.2 趋势检测结果（通俗版）

**这是最常用的模式**，判断数据是涨是跌。

```json
{
  "detection": {
    "trend_direction": "increasing",
    "sen_slope": 0.0234,
    "p_value": 0.0012,
    "statistical_significance": true,
    "interpretation": "检测到明显的上升趋势"
  }
}
```

| 字段 | 通俗解释 | 怎么用 |
|------|---------|--------|
| `trend_direction` | **趋势方向** | `"increasing"` = 上涨 📈<br>`"decreasing"` = 下跌 📉<br>`"no trend"` = 没有明显趋势 ➡️ |
| `sen_slope` | **变化速度**（斜率） | 数字越大变化越快。比如 0.02 表示平均每个时间单位增加 0.02 |
| `p_value` | **结果可信度** | 越小越可信。< 0.05 表示结果很可靠 |
| `statistical_significance` | **结果是否可靠** | `true` = 可以相信这个结论<br>`false` = 结论不太确定 |
| `interpretation` | **结论的中文描述** | 直接显示给用户看 |

**前端展示建议**：
```
┌─────────────────────────────────────────┐
│ 📈 趋势分析结果                          │
├─────────────────────────────────────────┤
│                                         │
│  趋势方向：上涨 📈                       │
│  变化速度：每天增加约 2.3%               │
│  结论可靠性：高 ✓                        │
│                                         │
│  [查看趋势图表]                          │
│                                         │
└─────────────────────────────────────────┘
```

### 3.3 趋势分解结果（通俗版）

把数据拆成几个部分来分析。

```json
{
  "decomposition": {
    "trend": [...],
    "seasonal": [...],
    "residual": [...]
  }
}
```

| 字段 | 通俗解释 | 用途 |
|------|---------|------|
| `trend` | **长期趋势线** | 去掉波动后的整体走向，用来画趋势线图 |
| `seasonal` | **周期性波动** | 比如"每周一销量低，周末销量高"这种规律 |
| `residual` | **随机波动** | 去掉趋势和周期后剩下的随机变化，一般不用展示 |

## 4. 单变量预测算法

### 4.1 这个算法是干什么的？

单变量预测用来回答这类问题：
- "预测一下明天的销售额"
- "下周的访问量大概是多少？"
- "未来30天的趋势会怎样？"

## 5. 多变量预测算法

### 5.1 这个算法是干什么的？

多变量预测考虑多个因素来预测，比如：
- "根据天气、节假日、促销活动，预测销售额"
- "综合多个指标预测未来趋势"

**特点**：综合多个相关因素，预测更准确。

| 字段 | 通俗解释 | 怎么用 |
|------|---------|--------|

| `timestamps` | **对应时间点** | 每个预测值对应的时间 |

### 5.3 metrics（模型评估指标）是什么意思？

这些数字告诉你**模型预测得准不准**：

| 指标 | 通俗解释 | 怎么判断好坏 |
|------|---------|-------------|
| `rmse` | **平均误差大小** | 越小越好。比如 5.23 表示预测值平均偏差约 5.23 |
| `mae` | **平均绝对误差** | 越小越好。比如 3.45 表示平均每次预测偏差 3.45 |
| `r2` | **模型准确度评分** | 0~1 之间，越接近 1 越准。0.89 表示很准确 |

**r2 评分参考**：
- 0.9 以上：非常准确 ⭐⭐⭐
- 0.7 ~ 0.9：比较准确 ⭐⭐
- 0.5 ~ 0.7：一般 ⭐
- 0.5 以下：不太准确

```javascript
      showBadge('📊 基础分析');
    }
  }

  // 3. 用原始数据画图表
  if (algorithm_result) {
    drawChart(algorithm_result);
  }
}
```

## 8. 常见问题

### Q: 我应该显示哪些内容给用户？

**必须显示**：
- `readable_result.llm_analysis` - AI 生成的分析文字

**建议显示**：
- 趋势方向（上涨/下跌）
- 预测值和预测范围
- 相关图表

**可选显示**（给想深入了解的用户）：
- 技术细节
- 模型评估指标

### Q: 数据用来画什么图？

| 算法类型 | 推荐图表 |
|---------|---------|
| 趋势分析 | 折线图（显示趋势线） |
| 单变量预测 | 折线图 + 置信区间阴影 |
| 多变量预测 | 折线图 |

### Q: 怎么判断结果是否可靠？

- 趋势分析：看 `statistical_significance`，`true` 表示可靠
- 预测分析：看 `r2` 指标，越接近 1 越准确
