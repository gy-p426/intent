## 1. 返回数据总览

### 1.1 我会收到什么？

当用户提问后，系统会返回一个 JSON 对象，包含以下主要内容：

```
┌─────────────────────────────────────────────────────────────┐
│                      返回数据结构                            │
├─────────────────────────────────────────────────────────────┤
│  step          → 当前执行到哪一步了                          │
│  status        → 这一步是否成功                              │
│  data          → 具体的数据内容（重点关注这里）               │
│  timestamp     → 返回时间                                    │
└─────────────────────────────────────────────────────────────┘
```

### 1.2 完整返回示例（v5.0 统一格式）

```json
{
  "step": "completed",
  "status": "completed",
  "data": {
    "algorithm_type": "trend",
    "algorithm_type_chinese": "趋势分析",
    "algorithm_result": {
      "解释": "【趋势检测分析结果】\n\n📌 关键发现：\n1. 检测到数据呈现上升趋势...",
      "算法结果": {
        "分析类型": "detection",
        "数据特征": {},
        "检测结果": {},
        "使用方法": "mann_kendall",
        "数据点数": 100
      }
    },
    "sql_statement": "SELECT timestamp, value FROM sales_data ORDER BY timestamp",
    "normalized_query": "分析销售数据的趋势变化",
    "execution_summary": "趋势分析完成，检测到上升趋势",
    "data_summary": {
      "input_rows": 100,
      "sql_execution_time": 125
    },
    "message": "趋势分析算法执行完成"
  },
  "timestamp": "2024-12-29T10:30:00.000Z"
}
```

### 1.3 字段说明（通俗版）

| 字段名 | 是什么意思 | 举例 |
|--------|-----------|------|
| `step` | 当前执行到哪一步 | `"completed"` 表示全部完成 |
| `status` | 这一步成功了吗 | `"completed"` 成功，`"error"` 失败 |
| `data.algorithm_type` | 用的是什么算法 | `"trend"` 趋势分析，`"predict"` 预测 |
| `data.algorithm_type_chinese` | 算法的中文名 | "趋势分析"、"预测分析" |
| `data.algorithm_result` | **🌟 最重要！统一格式的分析结果** | 包含 `解释` 和 `算法结果` 两个字段 |
| `data.message` | 简短的状态消息 | "趋势分析算法执行完成" |
| `data.sql_statement` | 执行的SQL语句 | 用于调试 |
| `data.data_summary` | 数据摘要信息 | 输入行数、执行时间等 |

## 2. 统一输出格式

### 2.1 这是什么？

从 v5.0 版本开始，所有算法的返回结果都采用统一的两字段格式：

```json
{
  "解释": "面向用户的通俗分析结论（纯文本）",
  "算法结果": {
    // 算法特定的详细数据（用于图表展示）
  }
}
```

### 2.2 为什么要统一格式？

| 优点 | 说明 |
|------|------|
| **简化前端处理** | 所有算法返回结构一致，前端代码更简洁 |
| **用户友好** | `解释` 字段直接展示给用户，无需额外处理 |
| **数据完整** | `算法结果` 保留所有技术细节，支持图表绑定 |
| **易于扩展** | 新增算法只需遵循相同格式 |

### 2.3 两个字段的用途

| 字段 | 类型 | 用途 | 前端展示建议 |
|------|------|------|-------------|
| `解释` | string | 给用户看的通俗分析结论 | 直接显示在页面主区域 |
| `算法结果` | object | 算法计算的详细数据 | 用于绑定图表、表格等可视化组件 |

### 2.4 `解释` 字段格式

`解释` 是一段格式化的纯文本，包含以下结构：

```
【分析结果标题】

📌 关键发现：
1. 第一个关键发现
2. 第二个关键发现
3. 第三个关键发现

💡 分析说明：
详细的分析说明文本...

📋 建议：
• 第一条建议
• 第二条建议
```

**前端展示建议**：
```
┌─────────────────────────────────────────────────────────────┐
│ 📊 分析结果                                                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【趋势检测分析结果】                                        │
│                                                             │
│  📌 关键发现：                                               │
│  1. 检测到数据呈现上升趋势，结论可靠（置信度：95%）          │
│  2. 增长速度：平稳（每个时间单位平均变化 0.0234）            │
│                                                             │
│  💡 分析说明：                                               │
│  分析结果表明，您的数据整体呈现上升趋势...                   │
│                                                             │
│  📋 建议：                                                   │
│  • 数据呈上升趋势，建议关注增长的可持续性                    │
│  • 可以考虑利用这一趋势进行预测和规划                        │
│                                                             │
│  [▼ 查看详细数据]                                           │

```

## 3. 趋势分析算法

### 3.1 这个算法是干什么的？

趋势分析用来回答这类问题：
- "销售额是在涨还是在跌？"
- "数据有没有周期性规律？"
- "这个趋势明显吗？"

趋势分析有两种模式：
- **趋势分解**（decomposition）：把数据拆成趋势、季节性、随机波动三部分
- **趋势检测**（detection）：判断数据是涨是跌，给出统计结论

### 3.3 趋势检测字段说明

| 字段 | 通俗解释 | 怎么用 |
|------|---------|--------|
| `趋势方向` | **趋势方向** | `"increasing"` = 上涨 📈<br>`"decreasing"` = 下跌 📉<br>`"no trend"` = 没有明显趋势 ➡️ |
| `Sen斜率` | **变化速度**（斜率） | 数字越大变化越快。比如 0.02 表示平均每个时间单位增加 0.02 |
| `p值` | **结果可信度** | 越小越可信。< 0.05 表示结果很可靠 |
| `统计显著性` | **结果是否可靠** | `true` = 可以相信这个结论<br>`false` = 结论不太确定 |
| `结果解释` | **结论的中文描述** | 直接显示给用户看 |

## 4. 单变量预测算法

### 4.1 这个算法是干什么的？

单变量预测用来回答这类问题：
- "预测一下明天的销售额"
- "下周的访问量大概是多少？"
- "未来30天的趋势会怎样？"

**特点**：只根据一个指标的历史数据来预测未来。

### 4.3 单变量预测字段说明

| 字段 | 通俗解释 | 怎么用 |
|------|---------|--------|
| `是否成功` | **预测是否成功** | `true` 成功，`false` 失败 |
| `预测值` | **预测值列表** | 这就是预测出来的数字！按时间顺序排列 |
| `时间点` | **对应的时间点** | 每个预测值对应哪一天/哪个时间 |
| `置信下限` | **预测下限** | 实际值大概率不会低于这个数 |
| `置信上限` | **预测上限** | 实际值大概率不会高于这个数 |
| `使用模型` | **用的什么模型** | `"prophet"` 或 `"arima"`，可以显示给用户 |
| `是否有季节性` | **数据有没有周期规律** | `true` = 有规律（如每周重复） |
| `趋势方向` | **整体趋势** | `"increasing"` 上涨，`"decreasing"` 下跌 |

### 4.4 置信区间是什么意思？

简单说：**预测值是一个范围，不是精确数字**

```
预测值: 112.3
置信下限: 107.1  ─┐
                  ├─ 实际值大概率在这个范围内
置信上限: 117.5  ─┘
```

**前端展示建议**：
```
┌─────────────────────────────────────────┐
│ 🔮 预测结果                              │
├─────────────────────────────────────────┤
│                                         │
│  明天预测销售额：112.3 元                │
│  预测范围：107.1 ~ 117.5 元              │
│                                         │
│  使用模型：Prophet                       │
│  数据特点：有周期性规律，整体上涨趋势     │
│                                         │
│  [查看预测图表]                          │
│                                         │
└─────────────────────────────────────────┘
```

## 5. 多变量预测算法

### 5.1 这个算法是干什么的？

多变量预测考虑多个因素来预测，比如：
- "根据天气、节假日、促销活动，预测销售额"
- "综合多个指标预测未来趋势"

**特点**：综合多个相关因素，预测更准确。

### 5.3 多变量预测字段说明

| 字段 | 通俗解释 | 怎么用 |
|------|---------|--------|
| `预测值` | **预测值列表** | 预测出来的数字 |
| `时间点` | **对应时间点** | 每个预测值对应的时间 |

| `是否复用模型` | **是否复用了之前的模型** | `true` = 用的是之前训练好的模型 |

### 5.4 评估指标是什么意思？

评估指标告诉你模型预测得准不准：

| 指标 | 通俗解释 | 怎么看 |
|------|---------|--------|
| `均方根误差` (RMSE) | **平均误差大小** | 越小越好，比如 5.23 表示平均误差约 5.23 |
| `平均绝对误差` (MAE) | **平均偏差** | 越小越好，比如 3.45 表示平均偏差约 3.45 |
| `决定系数` (R²) | **模型解释力** | 0-1之间，越接近1越好。0.89 表示模型能解释89%的变化 |

### 6.1 错误响应格式（v5.0 统一格式）

### 6.2 常见错误类型

| 错误类型 | 可能原因 | 建议处理 |
|----------|---------|---------|
| 数据点不足 | 历史数据太少 | 提示用户需要更多数据 |
| 数据格式错误 | 时间戳或数值格式不对 | 检查数据格式 |
| 服务超时 | 数据量太大或服务繁忙 | 稍后重试 |
| 模型训练失败 | 数据质量问题 | 检查数据是否有异常值 |

```javascript
function parseTrendResult(response) {
  const result = response.data.algorithm_result;
  const algorithmResult = result.算法结果;
  
  // 检查是否成功
  if (algorithmResult.是否成功 === false) {

  }
  
  // 判断分析类型
  if (algorithmResult.分解结果) {

      explanation: result.解释,

      residual: algorithmResult.分解结果.残差分量,
      metrics: algorithmResult.分解结果.分析指标
    };
  } else if (algorithmResult.检测结果) {
    // 趋势检测结果
    return {
      success: true,
      type: 'detection',
      explanation: result.解释,
      direction: algorithmResult.检测结果.趋势方向,
      slope: algorithmResult.检测结果.Sen斜率 || algorithmResult.检测结果.斜率,

}
```

### 8.4 兼容性处理

如果需要同时支持 v4.0 和 v5.0 格式，可以使用以下兼容代码：

```javascript
function parseResult(result) {
  // 检查是否为 v5.0 格式
  if (result.解释 !== undefined && result.算法结果 !== undefined) {
    // v5.0 格式
    return {
      version: 'v5.0',
      explanation: result.解释,
      data: result.算法结果
    };
  } else {
    // v4.0 格式 - 手动合并通俗摘要
    const summary = result.通俗摘要 || {};
    const explanation = [
      summary.标题 ? `【${summary.标题.replace(/[📊🔍🔮🎯]/g, '').trim()}】` : '',
      summary.关键发现 ? `\n\n📌 关键发现：\n${summary.关键发现.map((f, i) => `${i+1}. ${f}`).join('\n')}` : '',
      summary.详细解释 ? `\n\n💡 分析说明：\n${summary.详细解释}` : '',
      summary.建议 ? `\n\n📋 建议：\n${summary.建议.map(r => `• ${r}`).join('\n')}` : ''
    ].join('');
    
    // 移除通俗摘要，其余作为算法结果
    const { 通俗摘要, ...algorithmResult } = result;
    
    return {
      version: 'v4.0',
      explanation: explanation,
      data: algorithmResult
    };
  }
}
```

## 9. 常见问题

### Q1: v5.0 格式和 v4.0 有什么区别？

v5.0 将原来分散的字段统一为两个字段：
- `解释`：面向用户的通俗分析结论（纯文本）
- `算法结果`：算法计算的详细数据（用于图表）

### Q2: 为什么要改成统一格式？

- 简化前端处理逻辑
- 所有算法返回结构一致
- `解释` 字段可以直接展示给用户

### Q3: 如何判断分析是否成功？

检查 `算法结果.是否成功` 字段：
- `true` 或不存在该字段：分析成功
- `false`：分析失败，查看 `解释` 字段获取错误原因

### Q4: 置信区间怎么理解？

置信区间表示预测值的可能范围。例如：
- 预测值：100
- 置信下限：95
- 置信上限：105

表示实际值大概率在 95-105 之间。

### Q5: 趋势方向的值是什么意思？

| 值 | 含义 |
|----|------|
| `"increasing"` | 上升趋势 📈 |
| `"decreasing"` | 下降趋势 📉 |
| `"no trend"` | 无明显趋势 ➡️ |

### Q6: 如何选择趋势分析类型？

- **趋势分解**（decomposition）：想了解数据的组成部分（趋势、季节性、随机波动）
- **趋势检测**（detection）：只想知道数据是涨是跌

### Q7: 单变量预测和多变量预测有什么区别？

- **单变量预测**：只根据一个指标的历史数据预测（如：根据历史销售额预测未来销售额）
- **多变量预测**：综合多个因素预测（如：根据天气、节假日、促销活动预测销售额）
