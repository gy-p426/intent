### 2.3 提示词内容
```
因果分析要求:
1. dependent_variable: 必须指定一个因变量(结果变量)
2. independent_variables: 自动从数据库中寻找所有可能影响因变量的数值型字段,数量不限
   - 主动分析数据库schema,找出所有可能相关的数值型字段
   - 不要遗漏任何可能有用的字段
   - 字段数量没有限制,尽可能全面地包含所有潜在的影响因素
3. normalized_query: 用于从text-to-sql算法获取数据的自然语言
```

### 2.4 输出格式
```json
{
  "parameter_mapping": {
    "dependent_variable": "销售额",
    "independent_variables": ["广告投入", "促销活动", "季节", "价格", "库存", "客户数量", "访问量"]
  },
  "required_columns": ["销售额", "广告投入", "促销活动", "季节", "价格", "库存", "客户数量", "访问量"],
  "normalized_query": "获取销售数据的销售额、广告投入、促销活动、季节、价格、库存、客户数量、访问量共8列,返回销售额、广告投入、促销活动、季节、价格、库存、客户数量、访问量共8列数据"

## 5. 因果分析服务（Analyzer）✅

**文件**: `algorithm/analysis-algorithm/causal-service/app/services/analyzer.py`

**状态**: ✅ 正常（包含因果链功能）

### 5.1 核心功能
- [x] PC算法进行因果结构学习
- [x] 贝叶斯网络构建
- [x] **有监督因果分析**（目标导向）
- [x] **因果链发现**（完整路径）
- [x] 因果特征识别
- [x] 结果提取和格式化

### 5.2 分析流程
1. **数据预处理**
   - 转换为DataFrame
   - 验证数据质量
2. **识别因变量和自变量**
   - 第一列是因变量
   - 其他列是自变量
3. **使用PC算法发现完整因果网络**
   - 学习因果结构
   - 构建有向无环图（DAG）
4. **执行因果特征选择**
   - 识别对因变量有影响的特征
   - 计算相关系数和显著性
5. **提取因果子图**
   - 找到所有能到达目标变量的节点（祖先节点）
   - 提取子图
   - **移除冗余的直接边**（如果存在A->B->C，则移除A->C）
6. **构建贝叶斯网络**
   - 参数学习（最大似然估计）
7. **提取结果**
   - 提取所有因果关系（包括间接路径）
   - 识别非因果特征
   - 计算统计指标
8. **格式化响应**
   - 自然语言解释
   - 核心结论
   - 统计指标

### 5.3 因果链功能 ✅
**关键方法**:
- `_extract_causal_paths_to_target`: 找到所有能到达目标变量的节点
- `_extract_causal_subgraph`: 提取因果子图并移除冗余边
- `_extract_results_supervised`: 从图中提取所有边作为因果关系

**特性**:
- [x] 发现完整的因果链（A->B->C，其中C是因变量）
- [x] 自动移除冗余边（如果A->B->C存在，则移除A->C）
- [x] 包含直接和间接因果关系
- [x] 使用NetworkX的`ancestors`方法找到所有祖先节点

```

    ↓

    ↓
数据处理（CausalityProcessor）
    ├─ 数据填充
    ├─ 数据清洗（转换为数值）
    ├─ 数据验证
    └─ 构建算法配置
    ↓
算法执行（AlgorithmExecutor）
    ├─ 调用因果分析API
    └─ 返回结果
    ↓

    ├─ 构建贝叶斯网络
    └─ 格式化响应

LLM解释结果
    ↓
返回给用户
